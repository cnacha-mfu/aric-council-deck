# ARIC — เอกสารประกอบการพิจารณา สภามหาวิทยาลัย

โครงการจัดตั้งศูนย์นวัตกรรมด้านปัญญาประดิษฐ์และหุ่นยนต์ มหาวิทยาลัยแม่ฟ้าหลวง (MFU-ARIC)
ระยะที่ ๑ · ปีงบประมาณ พ.ศ. ๒๕๗๐–๒๕๗๑ — ๑๐ สไลด์
